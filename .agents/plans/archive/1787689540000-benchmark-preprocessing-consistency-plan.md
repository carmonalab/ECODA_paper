# Benchmark preprocessing consistency and Stephenson restoration

## Context

The current Scanpy preprocessing path does not remove samples by total cell count: `base_preprocessing()` applies per-cell `min_genes=100` and per-gene `min_cells=3`, while the legacy Seurat helper `remove_low_cellcount_samples()` is no longer called by the active Python pipeline. The current processed-artifact audit finds below-500-cell samples in Bassez, Lee, Smillie, and Zhang; Zhang additionally contains `Pre_P010_t` with 8 retained cells and `Pre_P018_b` with 437 retained cells. The current registry removed Stephenson's `benchmark_analysis` view in commit `6afb504` while retaining only the two batch-effect views, so the current benchmark notebook excludes Stephenson even though benchmark artifacts still exist.

Implement a shared Python sample-count filter, restore Stephenson as a dual-use benchmark plus batch-effect dataset, document the accepted old/new method differences, and define the exact reprocessing gates. Materialize this approved plan at `.agents/plans/1787689540000-benchmark-preprocessing-consistency-plan.md` when execution begins; do not move or rewrite the existing local onboarding plan.

3. **Keep the current scPoli/PILOT annotation handling and document why.**

## Assumptions & contingencies

- The sample threshold is an observation count before Scanpy's per-cell/per-gene filtering, with `>=500` retained. If the raw audit differs from the current processed-mirror inventory, the raw audit controls the rerun manifest and the discrepancy is recorded in `NOTES.md`.
- Missing/invalid sample IDs fail closed; they are not counted as a removable sample category.
- `Unknown` remains an explicit cell-type level and is never replaced with a biological label or silently dropped. If a downstream package still rejects it, stop and fix that package input contract rather than removing cells.
- The restored Stephenson benchmark subset is the pre-`6afb504` `Site == "Ncl"` view. If the source input no longer contains that column or subset, stop before changing the view and record the incompatibility for review.
 - Existing local benchmark h5ads are evidence only, except for the explicitly audited remote Stephenson benchmark h5ad and its retained annotation/result artifacts described in Step 6. The released rerun artifacts for Bassez, Smillie, Zhang, and Lee must come from staged/raw input and current checked-in code; no old result list or pre-filtered h5ad is accepted as a substitute.
