## Post 11 by @Yann.Sagon (2024-08-22T14:16:40.497Z)

Dear @Ludovic.Dumoulin[@Ludovic.Dumoulin](https://hpc-community.unige.ch/u/ludovic.dumoulin) thanks for the information. I was able to reproduce the issue. In fact, based on our understanding, the correct behavior is on Bamboo.
You need to source a file to enable module. You can test like that:
```
ssh login1.bamboo "source /etc/profile.d/modules.sh ; module load Julia; ml"
```
Best
Yann
edit: after more investigation from my colleague @Adrien.Albert[@Adrien.Albert](https://hpc-community.unige.ch/u/Adrien.Albert) it appears the initial users home directory wasn’t fully populated with correct `.bashrc`. If interested, you can copy all the files in `/etc/skel` (hiden files starting with `.`) in your home directory. Anyway, the workaround wrote in this post is correct as well.
