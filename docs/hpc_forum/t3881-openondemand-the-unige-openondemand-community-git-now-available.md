## :loudspeaker: Unige OpenOnDemand Community Git Now Available
Dear HPC users,
We’ve set up a Git repository for the Unige OpenOnDemand app to centralize development and make it easier for users to contribute.
:link: GitLab Repository: https://gitlab.unige.ch/hpc/unige-openondemand[https://gitlab.unige.ch/hpc/unige-openondemand](https://gitlab.unige.ch/hpc/unige-openondemand)
### :bullseye:Why This Matters
This repository is meant to:
:small_blue_diamond:Keep development organized and transparent
:small_blue_diamond:Allow users to report issues and suggest improvements
:small_blue_diamond:Make it easier for the community to contribute directly
### :light_bulb:How You Can Participate
:check_mark: Report issues – If you notice a bug or have a request, open a ticket
:check_mark: Share suggestions – Help improve OpenOnDemand for everyone
:check_mark: Contribute code – Submit merge requests to enhance the project
If you’re using OpenOnDemand on the UNIGE HPC clusters and want to get involved, feel free to check it out.
