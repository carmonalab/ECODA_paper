Dear HPC Users,
Shared directories are now displayed when you log in to the login node. This allows you to see each path along with its associated Unix group.
This information is useful if you want to add a colleague to a group to give them access to a shared directory.
```
======================================================================
                      Accessible Shared Directories                      
======================================================================

Folder                                 Group
-------------------------------------  ------------
/srv/beegfs/scratch/groups/dpnc        private_dpnc
/srv/beegfs/scratch/groups/dpnc/atlas  share_atlas
/srv/beegfs/scratch/groups/rodem       share_rodem
/srv/fast/share/rodem/                 share_rodem
```
If you experience any issues or unexpected behavior, please let us know.
