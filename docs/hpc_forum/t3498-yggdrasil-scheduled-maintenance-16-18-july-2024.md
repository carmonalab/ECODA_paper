## Post 1 by @Yann.Sagon (2024-06-18T07:41:40.990Z)

Dear users,
As just announced on the baobab-announce@ mailing list, we will perform software and hardware maintenance on the Yggdrasil HPC cluster from July 16 08AM until July 18 10AM, 2024.
You will receive an email when the maintenance is finished.
The cluster will be completely unavailable during this time, with no access at all (not even to retrieve files).
If you submit a job in the meantime, make sure that the expected wall time (duration) does not overlap with the start of the maintenance, or your job will be scheduled after the maintenance.
What will be done during this maintenance:
- Upgrade Slurm to version 24.05 (this is a major version upgrade Slurm Workload Manager - Release Notes[Slurm Workload Manager - Release Notes](https://slurm.schedmd.com/release_notes.html))
- Update all servers to the latest security and bugfix releases
- Re-install all nodes with latest security and bugfix releases
- Various fixes (replace a battery, correct scripts etc)
As we’ll be quite busy during th maintenance we won’t be providing user support this week unless there is an emergency
Thank you for your understanding.
Best regards,
The HPC Team
