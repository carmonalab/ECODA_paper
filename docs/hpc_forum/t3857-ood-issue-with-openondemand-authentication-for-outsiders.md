## Post 1 by @Adrien.Albert (2025-03-11T16:16:15.282Z)

Dear HPC Users,
We recently encountered issues with some users (Outsiders) and OpenOnDemand authentication. Certain switch information was not correctly propagated in our Unige authentication system, preventing the link with HPC accounts.
This issue has now been resolved, and new registrations/extensions will automatically take this fix into account. However, some accounts still lack this information and may continue to encounter an authentication error when logging into OpenOnDemand.
If you experience this issue, please follow these steps:
- Authenticate at:
- :point_right: https://openondemand.baobab.hpc.unige.ch/[https://openondemand.baobab.hpc.unige.ch/](https://openondemand.baobab.hpc.unige.ch/)
- Access and copy the full details of your authentication session from:
- :point_right: https://openondemand.baobab.hpc.unige.ch/Shibboleth.sso/Session[https://openondemand.baobab.hpc.unige.ch/Shibboleth.sso/Session](https://openondemand.baobab.hpc.unige.ch/Shibboleth.sso/Session)
- Send us an email with these details so we can update your profile accordingly.
Thank you for your cooperation! :rocket:
